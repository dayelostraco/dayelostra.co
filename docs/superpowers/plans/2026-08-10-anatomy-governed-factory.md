# Anatomy of a Governed AI Factory — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish a sanitized, diagrammed reference-architecture + eval-methodology Insights deep-dive on dayelostra.co that lets a skeptical engineer judge the governed-factory *mechanics*, not just the outcomes.

**Architecture:** One new Astro content-collection entry (`src/content/insights/anatomy-of-a-governed-factory/index.md`) — prose in the existing essay voice plus three hand-authored, theme-aware inline SVG diagrams. Same pipeline as the other essays (auto OG card in CI, RSS, print stylesheet). No code, config, thresholds, or CUI.

**Tech Stack:** Astro 5 content collections (glob loader, zod schema in `src/content.config.ts`), Tailwind, inline SVG, pandoc/tectonic NOT involved (this is web content, not the resume).

## Global Constraints
- **No em-dashes** in any prose (use periods/colons/commas/parentheses). Verbatim user rule.
- **OPSEC:** no source, configs, exact threshold values, prompts, agent logic, CUI, or classified specifics. Stay strictly within concepts already public on colophon.build (Stationarius, Colloquy, Decretum, Change Control Board, five-lens review).
- **Voice:** first-person / org-framed "we", matching `swap-the-model-keep-the-ato` and `i-have-a-routing-table`.
- **Length:** ~1,800-2,200 words, readTime "~9 min read".
- **Frontmatter date:** `2026-08-07`. **Slug/dir:** `anatomy-of-a-governed-factory`. **draft:** false.
- **Diagrams:** theme-aware (must read in light AND dark), each wrapped in a `overflow-x:auto` container, `role="img"` + `<title>`/`<desc>` for a11y (the CI axe gate blocks deploy on violations).
- **Cross-link** into the trio: `/insights/compliance-is-a-byproduct/` and `/insights/i-have-a-routing-table/`.
- Every commit: build must pass (`npm run build`). Deploy is automatic on push to `main`; verify live after.

## File structure
- **Create:** `src/content/insights/anatomy-of-a-governed-factory/index.md` — the whole deliverable (frontmatter + prose + 3 inline SVGs).
- **(Fallback only, if inline SVG is stripped):** `src/content/insights/anatomy-of-a-governed-factory/diagram-{1,2,3}.svg` + `<img>` references.
- No other files change. OG card `og-insights-anatomy-of-a-governed-factory.png` is generated by CI (`scripts/og/render-posts.mjs`), not committed.
